Detailed Description

template<std::size_t Capacity>
class bno08x::shtp_uart::FrameDecoder< Capacity >

Byte-at-a-time decoder for frames received from the hub.

Push() every received byte. When it returns Event::ShtpFrame, Data() and Size() hold the SHTP transfer (protocol ID removed) until the next Push(). Event::BufferStatus updates BufferSpace(). Bytes outside a frame are ignored, and a frame that overflows Capacity or has an unknown protocol ID is reported as Event::Dropped.

Template Parameters
CapacityLargest frame payload kept, protocol ID included.
