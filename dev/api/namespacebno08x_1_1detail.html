Call the port's GpioSet() and return its status.

A bool result is returned as-is; a void GpioSet() (the earlier contract) is treated as always successful. Any other return type is rejected at compile time so that an SDK status code (for example an esp_err_t, where 0 means success) cannot be read as a bool.

◆ kHasI2cAddressHooks

template<typename Port >
constexpr bool bno08x::detail::kHasI2cAddressHooks = HasI2cAddressHooks<Port>::value
inlineconstexpr

True when the port provides the optional I2C address hooks.

uint8_t GetI2cAddress() returns the 7-bit address the port talks to and bool SetI2cAddress(uint8_t) changes it (also while the bus is open). The driver uses them to reach the bootloader at 0x28 / 0x29 during a firmware update over I2C (datasheet 1000-3927 section 1.4) and to restore the application address afterwards.
