# BNO08x Driver API reference {#mainpage}

The classes, members and types of the HardFOC BNO08x driver, generated from the headers.

Start with BNO085, the driver, and bno08x::CommInterface, the interface your platform port implements. Sensor
identifiers are BNO085Sensor; decoded reports are SensorEvent (SH-2) and RvcSensorValue (UART-RVC); firmware
update options are DfuOptions and DfuMemoryImage.

The guides, with examples that compile, are on the documentation site: <a href="../">BNO08x Driver
documentation</a>.
